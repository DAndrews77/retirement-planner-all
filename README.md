# Retirement Planner

A public, privacy-first retirement planning tool designed for different ages, incomes, timelines, and portfolio structures.

## What it supports

- Working users and people who are already retired
- Any number of retirement, Roth, taxable, cash, or custom accounts
- Per-account balances, contributions, and optional return assumptions
- Pension, Social Security, and other dependable retirement income
- Inflation-adjusted withdrawals through a chosen planning age
- Local-only browser storage; no financial data is sent to a server
- Responsive phone, tablet, and desktop layouts

## Use

Open the GitHub Pages site, enter your planning assumptions, add at least one account, and select **Calculate plan**.

## Important

This is an educational planning estimate, not investment, tax, legal, or Social Security advice. Actual outcomes may differ materially.
